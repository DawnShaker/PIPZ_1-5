# Практикум з ІПЗ — лабораторні роботи №1–5

Автор: Кукіль Д. О., група ІПЗ-25.

Репозиторій підготовлено для лабораторної роботи №10 «Вебсервіс GitHub». За завданням розміщено проєкти №1 та №5; додатково збережено наявні роботи №2–4.

| Робота | Що міститься | Рішення для відкриття |
| --- | --- | --- |
| LAB1 | Консольна програма C++/CLI: розрахунки й операції з рядками | `LAB1/LAB1.slnx` |
| LAB2 | Проєкт Windows Forms на C++/CLI | `LAB2/LAB2.slnx` |
| LAB3 | C++/CLI-проєкт із наданого архіву; окремо збережено початковий C#-шаблон | `LAB3/CppCLI/LAB2.slnx`; шаблон: `LAB3/LAB3.slnx` |
| LAB4 | Проєкт Windows Forms на C++/CLI з меню та панеллю інструментів | `LAB4/LAB2.slnx` |
| LAB5 | Масиви CLR: напруженість електричного поля `E = F / q` і транспонування матриці | `LAB5/LAB5.slnx` |

## Відкриття проєктів

Використовуйте Visual Studio з підтримкою C++/CLI, Windows Forms, .NET Framework 4.7.2 і набором інструментів v145, зазначеним у C++-проєктах. Відкрийте відповідний `.slnx`, виберіть конфігурацію та виконайте складання.

Назви `LAB2` усередині LAB3 і LAB4 залишено як у наданих матеріалах. У LAB3 звичайний каталог `LAB3/` містить незаповнений C#-шаблон; вихідні файли C++/CLI відновлено з `LAB3.ZIP` у `CppCLI/`. Для LAB4 відкривайте саме `LAB2.slnx`: окремий кореневий `LAB4.vcxproj` не містить вихідних файлів.

Опубліковані вихідні файли скопійовано без зміни алгоритмів. XML-файли проєктів і наявність указаних у них локальних ресурсів перевірено. Складання та запуск усіх п'яти програм у межах Лаб10 не проводилися.

## Склад репозиторію

Включено вихідний код, рішення, файли проєктів і потрібні ресурси. Службові каталоги Visual Studio, виконувані файли, результати складання та дублікати архівів виключено. Звіти попередніх робіт не потрібні для складання та не завантажуються.
